
Design a modern, premium, minimal, operating-system-style onboarding and entry experience for a web-based business operating system called **ShopManager OS**.

The dashboard and internal modules are already completed.
DO NOT redesign the dashboard or existing internal pages.

This task is ONLY for designing the complete experience BEFORE entering the dashboard.

The experience should feel similar to:

* Android first-time setup
* ChromeOS onboarding
* modern SaaS workspace initialization
* Shopify/Stripe onboarding
* lightweight operating system boot experience

The product is NOT a generic ERP or accounting software.

It is:

# “A lightweight web-based operating system for running a shop.”

The design must feel:

* calm
* modern
* premium
* smooth
* focused
* minimal
* trustworthy
* intelligent

Avoid:

* corporate ERP styling
* heavy enterprise layouts
* unnecessary complexity
* excessive onboarding questions
* flashy AI-style interactions

The onboarding should feel:

* fast
* guided
* emotionally smooth
* welcoming
* OS-like

The user should feel:

> “I am entering my business workspace.”

NOT:

> “I opened a website.”
